Scheme distinction. The difference is a SCHEME difference, not an error. The reference uses the classical 7-karaka scheme (Sun..Moon, node excluded); the production engine uses the 8-karaka Jaimini scheme where Rahu is measured in reverse (30 - 0.8076 = 29.1924) and therefore takes AK, shifting every other karaka down one slot. Under the 7-karaka scheme the independent result reproduces the reference exactly for AK, AmK, BK, MK. Both schemes are reported; neither is discarded.
