# Lineage Wisdom — Source Register

Every entry in `src/lineage_wisdom.cpp` traces to a source listed here.
Quote policy (enforced at data-entry time):

- Sanskrit / medieval Hindi originals: public domain — quoted directly.
- Open-access CC-BY translations: short quotes, attribution kept.
- Modern copyrighted material (Bhagwan Ram's books, modern
  hagiographies): paraphrased; at most one short fair-use anchor
  sentence where the lineage itself publishes the text freely.
- An entry without a verifiable source is never added.

## Quoting rules recap

- Medieval originals: quote (with verse numbers where available).
- CC-BY translations: quote + attribution (trans. Jishnu Shankar, CC BY).
- Modern copyrighted: paraphrase; one-sentence lineage-published anchors
  only, attributed.
- Nothing invented; unverifiable content dropped.
- Benevolent framing only — consistent with `safety_validator.hpp`
  (Shanti / Paushtika / Raksha).
